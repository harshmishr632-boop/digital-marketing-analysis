## Overview
This project aims to analyze the effectiveness of various digital marketing campaign channels and understand customer behavior in response to these campaigns.

## Model Performance
- **Logistic Regression:** 89.25%
- **K-Nearest Neighbors (KNN):** 86.08%
- **Support Vector Machine (SVM):** 87.92%

## Key Findings
- Campaign channels significantly influence customer engagement and conversion rates.
- Customer behavior varies significantly across different demographics, influencing campaign strategies.

## Quick Start Guide
### Installation Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/harshmishr632-boop/digital-marketing-analysis.git
   ```
2. Navigate to the project directory:
   ```bash
   cd digital-marketing-analysis
   ```
3. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```
4. Run the Jupyter Notebook:
   ```bash
   jupyter notebook
   ```

## Project Structure
- `data/` : Contains datasets used for analysis.
- `notebooks/` : Jupyter notebooks for various analyses.
- `src/` : Source code for models and data processing.
- `requirements.txt` : Python packages required for the project.
- `README.md` : Project documentation.
