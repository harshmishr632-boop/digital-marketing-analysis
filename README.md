 📊 Digital Marketing Campaign Analysis

 🎯 Objective
Analyze marketing campaign performance to improve sales and user engagement.

🛠 Tools Used
Python (Pandas, Matplotlib)
Tableau
Jupyter Notebook

📂 Dataset
User data
Sales data
Device data

🔍 Key Analysis
 Device vs User Growth
 Campaign Performance
 Weekday Sales Trends

📈 Key Insights
Android users dominate conversions
 Weekday 4 shows highest sales
 Holiday season boosts engagement

💡 Recommendations
Increase campaigns during peak seasons
Focus on high-performing devices
 Remove low-performing campaigns
